# AYT Books

বাংলা বইয়ের অনলাইন লাইব্রেরি ও বুকশপ ওয়েবসাইট। পাঠকরা বই **ফ্রিতে অনলাইনে পড়তে** পারবেন এবং পছন্দ হলে **WhatsApp-এ অর্ডার** করে কিনতে পারবেন। কোনো ব্যাকএন্ড/ডাটাবেজ লাগে না — সম্পূর্ণ স্ট্যাটিক HTML/CSS/JS সাইট, তাই GitHub Pages-এ ফ্রিতে হোস্ট করা যায়।

---

## 📁 ফোল্ডার স্ট্রাকচার

```
aytbooks/
├── index.html            হোমপেজ
├── books.html             সকল বই (ক্যাটাগরি ফিল্টার + সার্চ)
├── book.html               একটি বইয়ের বিস্তারিত পেজ (?id=... দিয়ে বই লোড হয়)
├── about.html               আমাদের সম্পর্কে
├── contact.html            যোগাযোগ
├── 404.html                    পেজ না পাওয়া গেলে
├── README.md
└── assets/
    ├── css/style.css        সব স্টাইল
    ├── js/
    │   ├── data.js          ⭐ বই ও ক্যাটাগরির তথ্য — এখানেই নতুন বই যোগ করবেন
    │   └── app.js            রেন্ডারিং লজিক (এখানে সাধারণত কিছু পরিবর্তনের দরকার নেই)
    ├── pdfs/                  বইয়ের PDF ফাইল এখানে রাখুন
    ├── covers/                (ঐচ্ছিক) বইয়ের কভার ছবি এখানে রাখুন
    └── icons/favicon.svg
```

---

## ➕ নতুন বই কীভাবে যোগ করবেন

1. বইয়ের PDF ফাইলটি `assets/pdfs/` ফোল্ডারে রাখুন। ফাইলের নাম ইংরেজি/সংখ্যা/হাইফেন দিয়ে দিন, স্পেস বা বাংলা অক্ষর এড়িয়ে চলুন। যেমন: `bindhu-theke-britto.pdf`
2. (ঐচ্ছিক) বইয়ের কভার ছবি (jpg/png) থাকলে `assets/covers/` ফোল্ডারে রাখুন। কভার না দিলে ওয়েবসাইট স্বয়ংক্রিয়ভাবে একটি সুন্দর ডিজাইন করা কভার তৈরি করে দেবে (বইয়ের নাম দিয়ে)।
3. `assets/js/data.js` ফাইল খুলুন এবং `BOOKS` অ্যারেতে নিচের মতো একটি নতুন অবজেক্ট যোগ করুন (কমা দিয়ে আলাদা করে):

```js
{
  id: "bindhu-theke-britto",          // ইউনিক আইডি — অন্য কোনো বইয়ের সাথে না মেলে খেয়াল রাখুন
  title: "বিন্দু থেকে বৃত্ত",           // বাংলা শিরোনাম
  titleEn: "Bindu Theke Britto",       // ইংরেজি শিরোনাম (ঐচ্ছিক)
  author: "লেখকের নাম",
  editor: "",                          // না থাকলে খালি রাখুন ""
  publisher: "প্রকাশনীর নাম",
  category: "novel",                   // CATEGORIES থেকে একটি id ব্যবহার করুন
  language: "বাংলা",
  pages: 240,
  isbn: "",
  edition: "প্রথম সংস্করণ ২০২৪",
  price: 350,
  currency: "৳",
  coverColor: "#0f3d3e",               // অটো-কভারের রঙ (cover ছবি না দিলে ব্যবহৃত হবে)
  coverAccent: "#c9a227",
  description: "বইটি সম্পর্কে ২-৩ লাইনের বিবরণ লিখুন।",
  tags: ["ট্যাগ১", "ট্যাগ২"],
  pdf: "assets/pdfs/bindhu-theke-britto.pdf",
  cover: "",                           // কভার ছবি থাকলে path দিন, যেমন "assets/covers/bindhu.jpg"
  featured: false                      // হোমপেজে দেখাতে চাইলে true করুন
}
```

4. ফাইল সেভ করুন এবং GitHub-এ পুশ করুন (নিচের অংশ দেখুন) — ব্যাস, বইটি সাথে সাথে ওয়েবসাইটে দেখা যাবে।

## 🗂️ নতুন ক্যাটাগরি যোগ করা

একই `data.js` ফাইলে `CATEGORIES` অ্যারেতে যোগ করুন:

```js
{
  id: "travel",
  label: "ভ্রমণ কাহিনী",
  labelEn: "Travel",
  icon: "🧭",
  desc: "ভ্রমণ বিষয়ক বই ও অভিজ্ঞতার গল্প"
}
```

তারপর বইয়ের `category` ফিল্ডে `"travel"` ব্যবহার করলেই সেই বই এই ক্যাটাগরিতে দেখাবে।

## 📱 WhatsApp অর্ডার নম্বর পরিবর্তন

পুরো সাইটে একটি জায়গা থেকেই WhatsApp নম্বর নিয়ন্ত্রণ হয়:
`assets/js/app.js` ফাইলের একদম উপরে —

```js
const WHATSAPP_NUMBER = "8801786840952";
```

নম্বর পরিবর্তন করতে চাইলে এখানে বদলে দিন (দেশের কোডসহ, শুরুতে `+` বা `০` ছাড়া)।

## 🚀 GitHub Pages-এ পাবলিশ করবেন যেভাবে

1. [github.com](https://github.com)-এ একটি নতুন রিপোজিটরি তৈরি করুন, যেমন `aytbooks`।
2. এই পুরো ফোল্ডারটি রিপোজিটরিতে আপলোড/পুশ করুন:

```bash
cd aytbooks
git init
git add .
git commit -m "AYT Books website"
git branch -M main
git remote add origin https://github.com/<আপনার-ইউজারনেম>/aytbooks.git
git push -u origin main
```

3. GitHub রিপোজিটরির **Settings → Pages**-এ যান।
4. "Source" থেকে **branch: main, folder: / (root)** সিলেক্ট করে Save করুন।
5. কিছুক্ষণ পর সাইটটি এই লিংকে লাইভ হয়ে যাবে:
   `https://<আপনার-ইউজারনেম>.github.io/aytbooks/`

> নিজের ডোমেইন (যেমন `aytbooks.com`) যুক্ত করতে চাইলে একই Settings → Pages পেজে "Custom domain" অপশনে ডোমেইন বসিয়ে দিন এবং ডোমেইন প্রোভাইডারে CNAME/A রেকর্ড যোগ করুন।

## 🔍 লোকালি প্রিভিউ করবেন যেভাবে

ডবল ক্লিক করে `index.html` খুললেও কাজ করবে, তবে অনলাইন PDF রিডার ঠিকমতো কাজ করার জন্য একটি লোকাল সার্ভার দিয়ে চালানো ভালো:

```bash
cd aytbooks
python3 -m http.server 8080
```

তারপর ব্রাউজারে যান: `http://localhost:8080`
